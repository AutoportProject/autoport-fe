# 🚀 Autoport Frontend

Autoport 프로젝트의 프론트엔드 레포지토리입니다.

---

## 🛠 기술 스택

### 📌 프레임워크

- **React**
  - 컴포넌트 기반 개발 → 재사용성 및 유지보수성 향상
  - 풍부한 생태계로 협업 및 확장성에 유리

- **Next.js**
  - React 기반 풀스택 프레임워크
  - 파일 기반 라우팅 지원 → 빠른 개발 가능
  - SSR 지원 → SEO 최적화에 유리

---

### 📌 언어

- **TypeScript**
  - 정적 타입 지원 → 컴파일 단계에서 오류 검출
  - 대규모 프로젝트에서 유지보수성 향상
  - React와의 높은 호환성

---

### 📌 스타일링

- **Tailwind CSS**
  - 유틸리티 클래스 기반 → 빠른 UI 개발
  - 일관된 디자인 유지 가능

> styled-components는 JS 파일 크기 증가로 인한 성능 저하 우려로 인해 사용하지 않음

---

### 📌 패키지 매니저

- **pnpm**
  - 빠른 설치 속도
  - 효율적인 디스크 사용
  - 엄격한 의존성 관리로 충돌 방지

---

### 📌 UI 컴포넌트

- **shadcn/ui**
  - Tailwind 기반 UI 컴포넌트
  - 높은 커스터마이징 자유도

---

### 📌 배포

- **Vercel**
  - Next.js 최적화 배포 플랫폼
  - 간편한 배포 및 자동 CI/CD 지원
